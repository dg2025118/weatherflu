# 겨울은 정말 독감이 많이 걸리는 계절인가?
## 팀원
- 20421 이호연
## 질문
"축구 선수의 몸값(value_eur)은 정말 종합 능력치(overall)로 설명되는가"
## 왜 이 주제인가 (팀이 씁니다)
기온과 독감 의심 환자 비율을 비교하여 4계절중 겨울에 독감이 가장 심하게 유행하는지 확인하고 싶었다. 또한 이 주제를 감염 예방과 계절별 건강 관리 등 간호학 분야와 연결할 수 있을것 같아서 선정하였다.
