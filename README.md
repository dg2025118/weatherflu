1. 겨울은 정말 독감이 심한 계절인가?
2. 기온에 따라 독감 유행이 달라지는지 알아보기 위해 날씨 데이터와 독감 데이터를 선정했다. 기온과 독감 의심 환자 비율을 비교하여 4계절중 겨울에 독감이 가장 심하게 유행하는지 확인하고 싶었다. 또한 이 주제를 감염 예방과 계절별 건강 관리 등 간호학 분야와 연결할 수 있을것 같아서 선정하였다.
3. 뉴욕의 기온 데이터와 독감 데이터를 수집한다 - 두 데이터의 기간과 지역을 최대한 맞춘다. - 월별 평균기온과 독감 의심 환자 비율을 그래프로 나타낸다. - 기온과 독감 유행 시기를 비교하여 겨울에 독감이 가장 심한지 분석한다. - 분석 결과를 바탕으로 기온과 독감 유행의 관계를 해석한다.
